# Sistema Nacional de Gestión de Flota · Maqueta

Maqueta no operacional de la Unidad de Información y Análisis (UIA) de CONAF para el reemplazo de GESAD, requerimiento de la Sección Servicios Generales (GEFA).

- Base: ERS INF-LOG-TI-2026-V1 (15-10-2026), Prototipo Pool de Vehículos V7 y comprobantes de salida de GESAD.
- Vehículos y vencimientos: datos reales de Oficina Central (planilla al 28-09-2026), con números de motor y chasis enmascarados.
- Personas, RUT, pólizas y cargas de combustible: ficticios.
- Estándar de interfaz: `identidad/ESTANDAR_UI.md` de coipo_master_produccion.

Publicada con GitHub Pages: abrir `index.html`.
